# 100 Ways Human Dies

Short stories about how humanity ends through the misuse of AI. Each story is in English and Chinese, in `stories/`.

Read them at <https://x-du.github.io/100ways-human-die/>.

`scripts/build_site.py` builds the site into `dist/`. GitHub Pages publishes that build on every push to `main`.

Narration lives in `audio/`. `scripts/generate_audio.py` records any story that does not have an mp3 yet.
